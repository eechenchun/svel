# 使用说明

后台入口：`/admin/login`，账号是安装时填的管理员账号。

## 1. 仪表盘

显示已发布数、草稿数、分类数、标签数，以及运行环境：PHP 版本、数据库类型、表前缀、URL 档位、当前主题、启用插件、缓存 TTL、数据目录、日志文件路径。出现异常先看日志路径指向的文件末尾。

## 2. 文章

- 「文章 / 独立页面」两个入口分开管理；独立页面适合「关于」「联系」这类不进列表的内容。
- 列表可按状态（已发布 / 草稿）与标题筛选，支持发布、转草稿、删除（删除有二次确认）。
- 编辑页字段：标题、slug、类型、状态、发布时间、分类、标签、置顶、正文、摘要、封面、SEO 标题、SEO 描述、SEO 关键词。
- 摘要留空会自动从正文截取；SEO 标题留空用「标题 - 站点名」；SEO 描述留空自动截取正文。
- 中文标题不生成拼音。slug 留空时，英文标题会转成 `hello-world` 这样的形式；中文标题落成 `post-{id}`（独立页面为 `page-{id}`），随时可以手改。

### slug 改名与 301

1. 编辑页修改 slug，保存。
2. 程序把「旧地址 → 新地址」写进数据目录的 `redirect.php`，旧地址此后返回 301。
3. 连续改名会做链路压缩：A→B 再 B→C 后，访问 A 直接一跳跳到 C。
4. 会拒绝造成循环的改名，也会拒绝与保留字冲突的 slug（`admin`、`post`、`category`、`feed`、`sitemap` 等）。

分类、标签改名同样按这套规则处理。

## 3. 正文编辑器

编辑器由插件接管，安装时默认启用 Markdown 三栏编辑器。

### Markdown 三栏（默认）

- **左**：Markdown 源码；**中**：渲染结果；**右**：文档目录。
- 输入停止 300ms 后自动请求预览，预览与前台同一套渲染代码，所见即所得。
- 滚动同步：滚源码时预览按最近标题对齐，滚预览时源码跳到对应行；点击右侧目录条目可双向定位。
- 工具栏：加粗、斜体、H2/H3、链接、图片、引用、代码块、列表、分隔线、刷新预览。
- 快捷键：`Ctrl+B` 加粗、`Ctrl+I` 斜体、`Ctrl+K` 插入链接；`Tab` 插入四个空格。
- 宽度不足 1024px 时自动折叠为单列，避免横向滚动。

### 富文本

到「插件」页启用「富文本编辑器」即可接管编辑区，两个编辑器互斥，启用一个会自动停用另一个。富文本保存的内容按 HTML 存储，写入与输出都会经过标签、属性白名单过滤，`<script>`、事件属性、`javascript:` 链接一律剥离。

### 都不启用时

停用两个编辑器插件后，编辑区回到纯文本框，可以选 `Markdown` 或 `HTML` 直接写源码。此时不再有实时预览，适合救急或纯代码场景。

## 4. 分类与标签

- 分类：名称、slug、排序、描述。描述会用于分类页的 SEO description。删除分类不会删文章，文章会归入未分类。
- 标签：可在文章里直接输入新标签，保存时自动创建；也可在标签页单独改名。删除标签只解除关联，不影响文章。

## 5. 设置

- 站点名称与副标题：首页 title 输出「站点名 - 副标题」，副标题留空则只有站点名。
- 站点描述、关键词：用于 SEO description 与 RSS。
- 备案号：填写后显示在页脚，并链接到工信部备案系统。
- 每页文章数、缓存秒数（填 0 关闭缓存）。
- 默认分享图：文章没有封面时作为 `og:image`，建议 1200×630。
- 管理员账号：可改昵称、邮箱与密码；登录名不可改。

保存设置会自动清空页面缓存，前台立即生效。

## 6. 插件

- 「扫描插件目录」：把插件文件夹放进 `plugins/` 后点一下即可登记。
- 「上传并安装」：上传 zip，包内根目录要有 `plugin.json`。同名插件已存在时会拒绝安装，需先手工删除目录。
- 启用 / 停用即时生效，钩子缓存会重建，页面缓存会清空。
- 插件包安全限制：拒绝 `..` 与绝对路径、限制文件数与解压体积、解压后仍缺 `plugin.json` 直接失败。

## 7. 主题

主题放在 `themes/`，根文件 `theme.json`。切换主题会清空页面缓存。主题模板缺失时自动回退到 default，不会白屏。

## 8. 伪静态

页面显示当前档位与判定说明，可重新检测，也可手动切到 L1/L2/L3。下方给出 Apache、Nginx、Caddy、IIS 四份可直接复制的规则。换域名或换子目录后，记得回来点一次「重新检测」。

## 9. 缓存

- 前台页面命中缓存时响应头带 `X-Svel-Cache: HIT`，未命中为 `MISS`。
- 后台任何写操作（发文、改分类、改设置、切主题、启停插件）都会清空页面缓存。
- 缓存文件按 URL 哈希分两级目录存放，写入用临时文件 rename，命中时直接输出，不进入控制器。
- 404 页也会缓存，但 TTL 取「缓存秒数」与 300 秒的较小值，避免错误页长期驻留。
